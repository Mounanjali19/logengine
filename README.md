# LogEngine

A full-stack log monitoring and analysis platform built using Spring Boot, MySQL, and React.

## Features

- Log ingestion API
- Pagination support
- Log filtering
- Anomaly detection
- Swagger API docs
- React dashboard
- WebSocket-ready architecture
- MySQL persistence

## Tech Stack

Backend:
- Spring Boot
- Spring Data JPA
- MySQL
- Swagger/OpenAPI

Frontend:
- React
- Axios

## Run Backend

```bash
./mvnw spring-boot:run
```

## Run Frontend

```bash
npm install
npm run dev
```
